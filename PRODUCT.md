# Product

## Register

brand

## Users

Hiring teams, founders, and collaborators evaluating Bolarin Olabisi for senior React Native development. They need to see the mobile products, open the real store and testing links, and get in touch or download the CV.

## Product Purpose

A personal portfolio for Bolarin Olabisi, a Senior React Native Developer based in Lagos and working with remote teams. Mobile product ownership is the main story: shaping decisions, leading delivery, and improving the product after launch. Backend skills, AI feature development, and system designs support it. His agentic coding workflow uses Codex, with engineering judgment, review, and verification remaining his responsibility. A short personal note shares that he is currently learning cloud engineering.

## Brand Personality

Confident, precise, hands-on. Show real work with concise language and an expressive visual presentation.

## Anti-references

Generic generated portfolio templates, invented experience, App Store screenshots, fake phone mockups, oversized project descriptions, and repeated boxed feature grids. The CV is a reference, never a marketing claim. Backend and AI skills support the senior React Native focus rather than replacing it. Do not restore Doc Explain or claim unverified AI tools, models, or RAG experience.

## Design Principles

- Lead with the person and senior React Native expertise.
- Show product ownership through real leadership and post-release work from the CV, not a list of completed tasks.
- Make app security and privacy visible through authentication, access control, sensitive-data handling, and code review. Do not imply security certifications, audits, or compliance guarantees.
- Present mobile projects concisely and retain their correct release status. Use original interactive typography rather than App Store imagery.
- Keep summaries brief and links easy to find.
- Keep system designs compact as the collection grows.
- Review changes locally before publishing, as explicitly requested.

## Accessibility & Inclusion

Readable white text on the requested dark theme, visible keyboard focus, accessible navigation, reduced-motion support, and responsive layouts from small phones to wide desktops.
